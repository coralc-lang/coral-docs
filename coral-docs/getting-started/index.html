Install Coral

The Coral compiler is coralc. The installers download the toolchain, build it for your platform, and place it under a single home directory (~/.coral on Linux and macOS, %USERPROFILE%\.coral on Windows). A single command is enough on each platform.

Linux and macOS

curl -fsSL https://raw.githubusercontent.com/coralc-lang/coralc/main/install.sh | sh

Needs git, make, and a C compiler (cc). It clones the repository if it is run outside a checkout, runs make linux, installs to ~/.coral/bin and ~/.coral/lib, and adds ~/.coral/bin to your PATH (appended to ~/.profile, ~/.bashrc, and ~/.zshrc). Restart the shell afterwards. Override the location with CORAL_HOME=... or pass --prefix DIR.

Windows (PowerShell)

irm https://raw.githubusercontent.com/coralc-lang/coralc/main/install.ps1 | iex

Needs git and gcc (w64devkit or mingw-w64); make is used when present. It clones the repository if needed, builds from dist/coralc-windows.c via make windows, installs to %USERPROFILE%\.coral\bin, and adds that directory to the user PATH. Restart the terminal. Override the location with -Prefix DIR.

Use

coralc init myproject
cd myproject
coralc build
coralc run

coralc file.crl       # compile a single file
coralc --serve        # language server on stdio
coralc --help

Editor extensions

Prebuilt support is committed in the compiler repository under extensions/.

Zed — installs automatically

curl -fsSL https://raw.githubusercontent.com/coralc-lang/coralc/main/extensions/zed/install.sh | sh
irm https://raw.githubusercontent.com/coralc-lang/coralc/main/extensions/zed/install.ps1 | iex

The Zed package ships a prebuilt wasm, so it needs no Rust, clang, or tree-sitter. Restart Zed afterwards. It provides syntax highlighting, outline, brackets and indentation, and starts coralc --serve when coralc is on PATH.

VS Code, VSCodium, Cursor, Windsurf, Positron, Kiro — download only

The downloader saves the .vsix to your Downloads folder. It does not install it, because the script cannot know which fork you use.

curl -fsSL https://raw.githubusercontent.com/coralc-lang/coralc/main/extensions/vscode/download.sh | sh
irm https://raw.githubusercontent.com/coralc-lang/coralc/main/extensions/vscode/download.ps1 | iex

Then install it with your editor's CLI (the file name carries the version, here 0.4.0):

code --install-extension ~/Downloads/coral-0.4.0.vsix

codium, cursor, windsurf, positron, and kiro also accept --install-extension. In any fork without a CLI, open the Extensions view, click the ... menu, and choose Install from VSIX....

Or download directly: coral-0.4.0.vsix.

What gets installed

ItemLocationContents
Compiler~/.coral/bin/coralc (%USERPROFILE%\.coral\bin\coralc.exe)The coralc driver and language server (coralc --serve).
Standard library~/.coral/lib (%USERPROFILE%\.coral\lib)The lib/ tree the compiler resolves import(lib) against.
PATHYour shell profile, or the user environmentAdds the compiler's bin directory so coralc is on PATH.

Notes

  • Both installers require the pre-generated sources dist/coralc-linux.c and dist/coralc-windows.c to be committed and pushed with the repository. The make linux-free fallback path compiles dist/coralc-linux.c directly with cc; the Windows equivalent compiles dist/coralc-windows.c with gcc.
  • The Windows path is still untested here, for lack of a mingw toolchain; treat it as the intended flow rather than a verified one.
  • To verify the install, run coralc --version in a fresh shell.

With the compiler installed, continue to the Textbook, or set up your editor with the Tooling notes.
