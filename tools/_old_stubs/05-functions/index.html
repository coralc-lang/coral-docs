Chapter 05 · Functions

Functions are typed declarations

Coral's current sample shows return types before function names, explicit parameter types, and function types that can be stored in fields.

Starter · narrow syntax confirmed by sample

A function declaration

struct(i32, i32) makePair()
{
    return (2, 3);
}

The return type is a tuple type, followed by the function name and parameter list. The sample returns a pair and later reads its elements with one-based tuple fields.

A function value

struct CallbackBox<T, U> {
    T(U, i32) callback;
}

This comes from the user's current language example. More complete instruction on calls, parameter passing, generic functions, and ABI must wait for compiler-checked examples.
