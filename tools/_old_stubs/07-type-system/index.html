Aggregate types

Coral aggregates can put several typed values together. The current source demonstrates named struct fields, enum and variant declarations, and tuple values with positional fields.

  • Named fields: use a struct when field names explain each component.
  • Positional fields: tuple components are selected by their place in the tuple, as in a.1 and a.2.
  • Tuple type spelling: the sample writes struct(i32, i32).
  • Tuple value spelling: the sample returns (2, 3).
