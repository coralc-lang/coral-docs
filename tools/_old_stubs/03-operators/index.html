Part I · Chapter 03

Operators and expressions

An operator is a symbol that asks the program to do something with one or more values. This chapter will move from recognizing symbols to understanding what the compiler guarantees about them.

Chapter contents · semantics require compiler tests

The old manuscript makes detailed claims about overflow, short-circuiting, precedence, shifts, and pointer operations. Those claims must be checked against the current compiler before being taught as rules.
