Chapter 03 · Section 3.5

Pointers, casts, and size queries

These operators sit close to memory and representation. Small syntax mistakes can change what a program reads or writes, so this page is a map of topics to verify, not instructions to experiment with unsafe code.

Outline lesson · do not treat as an operational reference yet

Address and dereference

The old book discusses address-of and dereference operators, and the lexer includes ampersand and star tokens. Those facts do not prove the complete pointer grammar or safety conditions. Before teaching these operations, establish the pointer declarations that the current compiler accepts and create bounded tests.

Subscripts and casts

The old chapter also covers subscripting and casting. We must check the current grammar reference and compile examples before describing cast syntax, pointer indexing, or whether conversions preserve sign or width.

Size queries

The lexer includes a built-in sizeof token. A future lesson should explain what values it accepts, whether it runs at compile time, and exactly what result it returns for Coral types. A name alone does not answer those questions.

Safe learning order

  1. Read the current parser and type-checker rules.
  2. Use compiler tests on harmless local values first.
  3. Only then demonstrate memory reads and writes.
  4. Explain platform and alignment assumptions explicitly.
