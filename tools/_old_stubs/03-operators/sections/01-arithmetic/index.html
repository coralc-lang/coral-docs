Arithmetic and assignment

Arithmetic operators are short symbols for familiar calculations. The lexer gives each spelling a token; the compiler determines which operands and result types are legal.

Vocabulary-confirmed · behavior examples pending

Five familiar arithmetic marks

The lexer names tokens for these spellings:

+   -   *   /   %

People commonly use them for addition, subtraction, multiplication, division, and remainder. The current source sample demonstrates + in an expression. The other token names show that the lexer recognizes the spellings, but we still need compiler-checked examples to specify their types and edge behavior.

Assignment is a different job

A single equals sign, =, assigns or initializes a value in the shown declaration:

var total = 4;
total = total + 1;

The second line is an illustrative assignment example; compile it before treating it as verified syntax. The key reading distinction is that the plus sign calculates, while the equals sign stores a value into a named place.

Compound assignment spellings

The token list includes combined forms such as +=, -=, *=, /=, and %=. Their spellings suggest updating a value using an operation, but equivalence to an expanded assignment and evaluation count should be tested.

Beginner practice

When you see a + b, first identify the two values. Then ask what type each one has. Only after that should you predict the result. Types matter because the same symbol can be checked differently for integer and floating-point operands.

What is not yet promised

This page does not claim integer division rounding, remainder sign rules, overflow behavior, divide-by-zero behavior, or implicit conversions. Those belong in compiler tests and a later semantic reference.
