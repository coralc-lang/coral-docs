Compiler and editor tooling

Good tools help you answer practical questions: did the compiler accept this program, where did an error happen, and what does the editor know about the code?

Tooling status linked to current docs

Compiler first, editor second

The compiler is the authority for whether code builds. Editor features such as diagnostics, hover, navigation, and completion depend on the language server and may be incomplete. Syntax coloring is a separate feature and can continue to work even when semantic editor features are not implemented.

Tree-sitter in the browser

The docs-site contains a browser-compatible Coral grammar module and node metadata. Browser highlighting still needs a compatible web-tree-sitter runtime, then it can use the Coral highlights query to identify code spans. Grammar captures recognize syntax shape; they do not prove a name's resolved type.
