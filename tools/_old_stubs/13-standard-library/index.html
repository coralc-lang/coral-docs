Part IV · Chapter 13

The standard library

The standard library is where language syntax meets practical work: printing, strings, collections, operating-system services, and more.

Curriculum planned · API inventory required

Learn from APIs that exist

The old manuscript describes many collections and services. Before turning each into a lesson, inventory the modules and public declarations in the current library. Each example should compile against the current exports.

Topics to teach as separate lessons

  • Finding modules and public names
  • Printing and formatting values
  • Strings, bytes, and UTF-8
  • Arrays and collection APIs
  • Filesystem and operating-system services
  • Time, duration, and clocks
  • Errors and return conventions

Teaching rule

Each API lesson should answer three plain questions: what problem does this tool solve, what inputs does it need, and what does it return or change? Then show a small working example and name the compiler/library version it was checked with.

Do not promise a collection merely because it appears in the old textbook. Confirm its module, export, and current behavior first.
