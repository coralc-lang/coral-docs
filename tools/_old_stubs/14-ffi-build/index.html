Foreign interfaces and linking

A systems program sometimes needs to call code written in another language or supplied by the operating system. At that boundary, names, types, calling conventions, and linked libraries must agree.

Planned chapter · examples need validation against the current compiler

Calling across a language boundary

A foreign-function interface (FFI) is the set of rules that lets Coral code call an external function, or lets external code call Coral. Declaring a function is only one part of the job: the compiler and linker must agree on the symbol name, argument layout, return layout, and calling convention.

Why examples must be target-specific

A declaration that links on one operating system may not link on another because libraries, symbol names, and ABI conventions can differ. Every complete example in this chapter should name the target it was tested on and show the exact build command that succeeded. Until those examples are checked, this page is an outline, not a current build guide.
