Chapter 01 · Section 1.3

Modern features without a syntax reset

Coral adds richer ways to describe data and behavior while keeping declarations recognizable. This lesson introduces the shapes shown in the current source; later chapters will examine their rules.

Beginner lesson · declaration forms from current source

Generics: one shape, several types

A generic declaration describes a family of types instead of just one. In the example, T and U are placeholders. They let the struct’s fields use types that will be selected when a concrete generic type is used.

struct foo<T, U> {
    T a;
    U b;
}

For a beginner, think of T and U as labeled blank spaces in the type. The compiler still needs actual types when the generic is used; the blanks do not make the fields untyped.

Enums: a named set of choices

The source declares an enum with three named cases:

enum Color {
    Red,
    Green,
    Blue
}

This tells us that the declaration can list named alternatives. It does not, by itself, tell us how values are represented in memory or how matching on them is written. Those are separate questions for a verified lesson.

Variants: cases can carry data

The sample also has a generic variant with one data-carrying case and one bare case:

variant Option<T> {
    Some { value; },
    None
}

A useful first mental model is: an Option is either the Some case, which has a value, or the None case, which does not show a field. The sample demonstrates this declaration shape; construction, inspection, and exhaustiveness rules need their own compiler-checked examples.

Extensions: behavior beside a type

The current source uses an extend block to write a method-like declaration:

extend Option {
    T get_value()
    {
        return value;
    }
}

The syntax visibly attaches a block of behavior to the named type. Whether this exact example builds, how it accesses a variant field, and how extension methods are selected are not proven by seeing it in a source file. We will check those details before making stronger claims.

The through-line

Generics, enums, variants, and extensions are modern features, but they are still declared using types, names, braces, and semicolons. Coral does not need to abandon its declaration-first C-family grammar to express richer programs.
