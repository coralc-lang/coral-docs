Read the type before the name

Coral’s declarations put type information in front. That remains true even when the type describes a function.

Beginner lesson · type-first forms from current source

Start with a simple field

i32 count;

Read from left to right: i32 is the type, and count is the field or variable name. The semicolon ends this declaration. A reader does not need to search after the name to discover its type.

A function begins with its result type

struct(i32, i32) foooo()
{
    return (2, 3);
}

The function returns a tuple made from two i32 values. Its name comes after that return type. The parentheses after the function name hold its parameters; here the list is empty. The braces contain the body, and return provides the result.

This is the same declaration-first reading style as a simple field, extended to a function.

Now read the function type

The current generic struct contains this field:

T(U, i32) fn;

Read it in pieces. The leading T is the function’s return type. The parentheses list its parameter types, U and i32. The final word, fn, names the field that stores this function value.

This form is designed to be read as a type followed by a name. C’s traditional function-pointer declarator often wraps the name in pointer punctuation; Coral’s spelling makes the function signature itself more direct. The language remains C-family in its declarations; this is a readability improvement to one type form.

Where do T and U come from?

struct foo<T, U> {
    T a;
    U b;
    T(U, i32) fn;
}

The angle brackets introduce generic parameters on this struct. Inside its body, T and U are used in field types. A particular use of the generic struct supplies concrete types for those parameters. This sample shows the declaration shape; the book will test instantiation syntax and type-checking rules separately.

Try reading one aloud

For T(U, i32) fn, say: “A function pointer of type T takes a U and an i32, and is named fn.” Reading the type aloud is a simple trick, but it prevents the function name and its type from getting mixed up.
