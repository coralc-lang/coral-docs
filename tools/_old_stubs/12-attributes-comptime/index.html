Part IV · Chapter 12

Attributes and compile-time work

An attribute is structured information attached to source code. It may change how the compiler treats a declaration, so its exact status matters.

Status-based lesson · consult current implementation notes

Parsed does not always mean applied

The current attributes document separates attributes the compiler honors from attributes it parses without applying semantics and attributes on the roadmap. That distinction is the central lesson: accepted spelling is not proof of an effect.

#[[no_drop_all]]

This spelling is documented in the source notes. Its placement and exact effect should be learned from the current status table, not inferred from the name.
