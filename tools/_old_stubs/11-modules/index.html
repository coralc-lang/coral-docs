Part IV · Chapter 11

Modules and imports

A module is a way to divide a program into named pieces. Imports let one piece refer to declarations made available by another.

Learning map · implementation differs by import form

Start with the current shape

The workspace contains src/lib.crl, which exposes a module using an import declaration. The exact source form is grounded in the current project; broader import forms are documented separately as implemented or planned.

mod main = import main;
