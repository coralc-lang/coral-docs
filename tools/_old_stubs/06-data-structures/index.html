Chapter 06 · Data structures

Grouping and choosing data

The verified starting point is the language's own aggregate syntax: generic structs, tuple types, enums, and variants.

Starter · shown forms are present in current sample

Generic struct

struct Pair<T, U> {
    T first;
    U second;
}

Enum and variant

enum Color {
    Red,
    Green,
    Blue
}

variant Option<T> {
    Some { value; },
    None
}

The sample establishes these declaration forms. It does not establish pattern matching, layout, default values, or the representation of variants; those need separate tests.
