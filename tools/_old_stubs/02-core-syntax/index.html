Part I · Chapter 02

Core syntax and declarations

A declaration is a sentence the compiler uses to introduce a named thing. Coral makes the type part of the beginning of that sentence. This chapter takes one small idea at a time.

Chapter contents · five separate lessons

These lessons use the current main.crl sample and the supplied lexer vocabulary. Where the vocabulary is all we know, a lesson says so; a token name is not treated as proof of every behavior.
