Identifiers and reserved words

An identifier is a name in your program. It lets you refer to a variable, function, field, type, or module without rewriting the thing itself.

Vocabulary lesson · naming rules need grammar confirmation

Names label declarations

i32 count = 42;

pub i32 add(i32 left, i32 right)
{
    return left + right;
}

Here, count, add, left, and right are identifiers. Names are how the later parts of a program refer back to declarations.

Keywords already have a job

The lexer has dedicated token kinds for words such as struct, enum, variant, extend, return, and var. These words carry language meaning in contexts where they are recognized, so they are not ordinary user-chosen names in those contexts.

What the token list does not specify

The lexer vocabulary alone does not give the full rule for legal identifier characters, case sensitivity, reserved words in every position, or naming conventions. Those details should come from the parser/lexer implementation and compiler tests, not from assumptions based on C.
