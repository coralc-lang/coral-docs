Initialization and mutation

Initialization gives a newly declared name its first value. Mutation changes a value after that declaration. These are related actions, but they happen at different moments.

Starter lesson · assignment form needs compiler check

Initialization happens at declaration

var count = 3;

The declaration creates the name count and gives it its starting value. The equals sign appears inside the declaration with its initializer.

Mutation changes an existing value

count = count + 1;

This line is an illustrative assignment form matching the C-family syntax shown in the old text. Compile a minimal program with the current compiler before relying on mutability or assignment rules as established facts.

Mutability is a compiler rule

Some languages use separate declaration forms for changeable and fixed names. The current lexer includes const and var, but token names alone do not tell us the full reassignment rules. A dedicated test should cover a mutable local, a constant local, reassignment, and a write through a pointer.
