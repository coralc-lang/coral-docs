Chapter 02 · Section 2.10

Scope: where a name can be used

A name’s scope is the region of the program where that name is visible. If the compiler cannot see a declaration from a particular place, code there cannot refer to it by that name.

Beginner lesson · nested-block behavior needs compiler tests

Braces make regions visible

pub void main()
{
    var outer = 1;
    {
        var inner = 2;
    }
}

This example illustrates an inner block surrounded by braces. Many C-family languages limit inner to that block. Confirm Coral’s exact name-visibility rule with a compiler test before depending on it.

Shadowing means reusing a name

Shadowing is when an inner declaration uses the same spelling as an outer declaration. Languages vary in whether this is allowed and what the inner name refers to. The older manuscript says Coral permits it; the current source and compiler should confirm that before the book teaches it as a rule.

How to check scope

Compile one case where an inner block uses an outer name, one case where an outer block tries to use an inner name, and one case where both declare the same name. The accepted and rejected examples together make a much clearer lesson than a definition alone.
