Source files and text

A source file is the text you give to the compiler. Before the compiler can understand declarations, it has to read the characters that make up the file.

Beginner lesson · current workspace uses .crl

Coral files in this project

The current workspace names its source files with the .crl extension. You can see examples in src/main.crl and src/lib.crl. The extension helps people and tools recognize the file; compiler acceptance is still determined by the build configuration and compiler.

Characters become tokens

The compiler does not understand a page of text all at once. It first reads characters and groups them into tokens: identifiers, built-in type names, punctuation, operators, literals, and keywords. The supplied TokenKind enum is a vocabulary list for that stage.

Encoding claims need a source

The old manuscript makes detailed claims about UTF-8 source handling. This lesson does not repeat them as fact until confirmed in the current lexer and file-reading path. Encoding behavior belongs to the compiler implementation, not just to the filename.
