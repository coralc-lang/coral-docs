Appendix E, Collections

This appendix is one volume of the Coral Standard Library API reference; for a guided tour of how these modules fit together, see Appendix A, A Tour of the Standard Library. Its companion volumes are Appendices D through K, each covering a group of the library.

std::collections

Imported via std::collections. Vec<T> is also re-exported as std::vec and prelude-imported; Arr<T, N> as std::arr.

Iteration: the iterable containers implement the built-in @iter marker trait, which the ranged for loop of Chapter 4 drives. Such a type supplies usize count(), T at(usize i), and, for bounded loops, IterRange range(usize start, usize end), all in an @iter extend block. The half-open bounds type is declared in std::collections::range:

coral
pub struct IterRange
{
    usize start;
    usize end;
}

Vec, Arr, Deque, RingBuf, Queue, LinkedList, PriorityQueue, and Bitset implement @iter; the associative containers (Map, HashMap, Set, Tree, Trie, Cache, UnorderedMap) do not, and are walked with each().
