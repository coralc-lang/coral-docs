Appendix H, Memory and Concurrency

This appendix is one volume of the Coral Standard Library API reference; for a guided tour of how these modules fit together, see Appendix A, A Tour of the Standard Library. Its companion volumes are Appendices D through K, each covering a group of the library.

66. std::concurrent::async, Stackful-fiber async runtime

Built on glibc ucontext. spawn creates a fiber, await parks the current fiber until a future resolves, and run/runOnce drive the scheduler.

pub variant AsyncError
{
    OutsideFiber { str msg; },
    NullFuture   { str msg; },
    SpawnFailed  { str msg; }
}

pub struct Future
{
    u8     state;         // FUTURE_PENDING / FUTURE_READY
    rawptr result;
    Fiber* waiters;
    Future* chanNext;
    bool   counted;
}

pub usize defaultFiberStackSize = 131072;   // 128 KiB

pub bool init()
pub Result<Future*, AsyncError> spawn(void(rawptr) fn, rawptr arg)
pub Result<rawptr, AsyncError>  await(Future* f)
pub Future* sleep(u64 ms)
pub bool    run()
pub void    runOnce()
pub Future* poolRun(ThreadPool* pool, void(rawptr) fn, rawptr arg)

pub struct AsyncChannel
{
    rawptr* buf;
    usize cap;
    usize count;
    usize head;
    Future* recvHead;
    Future* recvTail;

    bool    init(usize capacity)
    void    deinit()
    bool    send(rawptr value)
    Future* recv()
}
pub extend AsyncChannel : @drop { void drop(); }

State/step constants (FUTURE_*, FIBER_*, STEP_*) and the scheduler internals (Fiber, Scheduler, TimerEntry, _nowMs, _initScheduler, …) are non-pub and not part of the public surface.
