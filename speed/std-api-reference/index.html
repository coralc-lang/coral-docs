Standard Library API Reference

This document catalogues every pub export of the Coral standard library and the core/platform support modules it builds on. It is generated from the actual source tree under lib/ and reflects the current dialect.

  • Sources of truth: lib/core/**, lib/platform/**, and the per-target lib/std/x86_64/<target>/** trees. The primary target documented here is x86_64/linux; lib/std/x86_64/windows/** mirrors it with platform differences (noted where relevant).
  • Top-level manifest: lib/std/lib.crl re-exports the submodules; the per-target manifest is lib/std/x86_64/linux/lib.crl.
  • Signature syntax: RetType name(params). Tuple types are spelled struct(T, T) (never (T, T)). Generics are <T>, <T, U>, <T, usize N>, or <comptime N>; there are no generic bounds and no trait composition.
  • Visibility: the dialect has no per-method pub; every member declared in a pub struct/pub variant/pub enum/pub extend is public. Members named with a leading _ are internal helpers, listed here for completeness but not intended for direct use.
  • @drop: @drop is an inbuilt trait. Types that own heap memory provide an extend <T> : @drop { void drop() } block wiring their dispose() into the language's automatic cleanup.

1. core::cchar, C character type

pub distinct cchar = flag (arch)
{
    x86_64 => { i8 },
    else   => { u8 }
}

A cchar is a char-like C character whose signedness depends on the target architecture (signed i8 on x86_64, unsigned u8 elsewhere).

32. std::time, Wall-clock and monotonic time

Ported from the old std/core/time module. Each target implements the same public surface with its own native clock: the Linux build issues raw x86_64 syscalls (clock_gettime, gettimeofday, nanosleep, time); the Windows build calls QueryPerformanceCounter, GetSystemTimeAsFileTime, and Sleep. There is no libc in either path.

pub const CLOCK_REALTIME  : i32 = 0;
pub const CLOCK_MONOTONIC : i32 = 1;

pub struct Timespec { i64 sec; i64 nsec; }
pub struct Timeval  { i64 sec; i64 usec; }

pub Timespec nowMonotonic()                       // CLOCK_MONOTONIC
pub Timespec nowRealtime()                        // CLOCK_REALTIME
pub Timeval  nowTimeval()                         // gettimeofday / derived
pub u64      unixSeconds()                        // time(2) / file-time epoch
pub Timespec addTimespec(Timespec a, Timespec b)
pub Timespec subTimespec(Timespec a, Timespec b)
pub f64      timespecToF64(Timespec ts)           // sec + nsec * 1e-9
pub f64      timevalToF64(Timeval tv)             // sec + usec * 1e-6
pub void     sleepTimespec(Timespec ts)           // nanosleep / Sleep
pub void     sleepMs(u64 ms)
  • nowMonotonic() never jumps backwards and is the clock to use for measuring elapsed time; nowRealtime() is wall-clock and can move when the system time is adjusted.
  • sleepTimespec / sleepMs do not retry a shortened sleep; a signal can wake them early (matching the old module).
  • Timespec / Timeval are plain value types with no @drop.
import(lib) std::time { Timespec, nowMonotonic, subTimespec, sleepMs, timespecToF64 };

Timespec t0 = nowMonotonic();
sleepMs(10u);
Timespec t1 = nowMonotonic();
println(timespecToF64(subTimespec(t1, t0)));
